# 한글 꽃밭

사물에 적힌 자음과 모음이 만나 글자와 말이 되는 유아 한글 놀이 웹앱입니다.

고마워 · 사랑해 · 안녕 · 같이 놀자 · 아름다워 · 즐거워 · 행복해 · 신나 · 재밌어 · 흥겨워

소스 저장소: https://github.com/inachus76-design/hangeul-garden

## GitHub + Netlify 배포

코드는 GitHub에 저장하고, 웹사이트는 Netlify에서 배포합니다.

1. Netlify에 로그인합니다.
2. `Add new project` 또는 `Add new site`에서 Git 저장소를 가져오는 항목을 선택합니다.
3. GitHub 계정을 연결하고 `inachus76-design/hangeul-garden` 저장소를 선택합니다.
4. 배포 브랜치는 `main`, Base directory와 Build command는 비워 두고, Publish directory는 `.`으로 설정합니다.
5. 배포를 시작합니다. 성공하면 Netlify가 제공하는 HTTPS 주소로 앱을 사용할 수 있습니다.

저장소의 `netlify.toml`이 게시 폴더를 지정합니다. 별도 설치나 빌드 명령, API 키는 필요하지 않습니다.
Netlify와 저장소를 연결하면 이후 `main` 브랜치의 수정사항이 자동으로 배포됩니다.

## 사용하기

말을 누르거나 ‘말해 볼래요’ 버튼을 누르고 화면에 있는 말을 말해 주세요.
빠르기 조절, 잠깐 멈춤, 다시 보기, 소리 켜기·끄기를 사용할 수 있습니다.

- 10개 말, 30개 글자 장면과 서로 다른 완성 애니메이션
- 자모가 적힌 사물의 위치와 색이 바뀌는 놀이
- ‘ㅝ’는 ‘ㅜ+ㅓ’, ‘ㅘ’는 ‘ㅗ+ㅏ’가 먼저 만나는 과정
- ‘ㅐ’는 나누지 않고 하나의 모음으로 표시

Chrome 또는 Edge 등 음성 인식이 지원되는 브라우저에서 마이크 사용을 허용해 주세요.
기기와 브라우저에 따라 음성 인식 지원이 다르며, 말을 눌러서도 같은 놀이를 할 수 있습니다.
앱 자체는 이름, 녹음 파일, 학습 기록을 저장하지 않습니다. 브라우저의 음성 인식 서비스가 음성을 처리할 수 있습니다.

## 파일

`index.html`, `style.css`, `art.js`, `rides.js`, `objects.js`, `endings.js`, `app.js`가 앱을 구성합니다.
`netlify.toml`은 Netlify 배포 설정입니다. 파일들은 같은 폴더에 둡니다.

공식 안내: https://docs.netlify.com/build/configure-builds/file-based-configuration/

## 새 단어 추가
상단 ‘새 단어 추가’에서 한글 1~8글자(띄어쓰기 가능)를 입력하고 놀이 소재를 선택합니다. 미리보기 후 저장하면 단어 목록과 음성 선택에 반영됩니다. 최대 50개이며, 이 브라우저의 저장 공간에 보관됩니다. 다른 기기와 자동 공유되지 않습니다. 기존 사물 장면과 10가지 완성 장면을 조합해 애니메이션을 만듭니다.
